# 设计行迹产品规格

## 产品目标

设计师通过一张可旋转和缩放的中国三维地图展示项目足迹。第一版只做作品集，不接入未经核实的景区人流量和酒店价格。

## 第一版用户流程

1. 访客打开地图，看到中国板块和项目坐标。
2. 访客筛选省份、城市、类型、年份或代表作。
3. 访客点击项目坐标或左侧列表。
4. 地图定位项目，右侧显示项目信息。
5. 访客通过时间轴观看项目逐年点亮。
6. 设计师进入本地后台维护项目，不需要修改代码。

## 验收标准

- 画面只显示中国区域，不显示完整世界地图。
- Cesium 画布正常，可拖动、旋转和缩放。
- 至少 10 个项目正确显示。
- 筛选、详情、时间轴、后台增删改、上传、备份和恢复可用。
- 没有地形密钥或地图资源加载失败时不白屏。
- 电脑和手机页面不横向溢出。
- 项目数据错误使用中文提示。

## 当前边界

- 示例项目不是真实案例。
- 演示模式使用简化中国板块，不承诺测绘精度。
- 真实地形需要用户自己的 Cesium ion 密钥。
- 正式公开上线前必须复核中国地图合规与地图数据许可。
