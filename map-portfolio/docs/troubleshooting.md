# 常见问题

## 网页打不开

确认运行了：

```bash
cd "/Users/Apple_501/Desktop/设计师网站/map-portfolio"
npm run dev
```

终端必须保持打开。

## 4178 端口被占用

先确认占用进程是否属于本项目，不能直接关闭陌生程序。然后重新启动本项目。

## 显示“演示地形”

这是正常状态。没有 Cesium ion 密钥时使用简化中国板块。填写 `.env` 后重启即可尝试真实地形。

## 上传失败

- 只支持 JPG、PNG、WebP、AVIF。
- 单张图片不能超过 8MB。
- 检查 `public/uploads/` 是否可以写入。

## 项目位置不对

后台经度范围是 -180 到 180，纬度范围是 -90 到 90。国内常见位置经度约 73 到 135，纬度约 18 到 54。

## 数据修改错了

先用后台“备份数据”保存 JSON。需要恢复时点击“恢复备份”，恢复操作会替换当前全部项目。
