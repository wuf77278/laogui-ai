# 设计行迹

这是“设计师三维中国地图”的第一版可运行原型。

## 当前功能

- 三维中国地形板块
- 鼠标或手指拖动旋转
- 放大、缩小和恢复全景
- 我的作品、旅游热度、酒店价格三种模式
- 发光项目点、热度光柱和价格光束
- 项目详情面板
- 年份时间轴
- 电脑和手机界面适配

当前使用的是示意数据。地图轮廓和地形为艺术化原型，不用于测量和导航。

## 打开方式

在“设计师网站”目录运行：

```bash
python3 -m http.server 4178 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:4178/map-portfolio/
```

## 文件说明

- `index.html`：页面结构
- `styles.css`：界面视觉和手机适配
- `app.js`：三维地图、光柱、模式切换和交互
- `DEVELOPMENT_PLAN.md`：完整开发方案
